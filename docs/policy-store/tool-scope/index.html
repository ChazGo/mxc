Initial Policy Store Tool Scope

A deliberately tight Windows/OpenClaw seed: ten concrete tool identities with actionable policy evidence and enough variety to validate the catalog contract before expanding its coverage.

Decision rules

Scoping criteria

The initial set favors reviewable policy shapes over broad catalog coverage.

  1. 1

    Supports the Windows/OpenClaw pilot and has a concrete executable or plugin identity.

  2. 2

    Has observed requirements that a sandbox policy floor can address.

  3. 3

    Has a Windows installation and execution path, not a macOS-only dependency.

  4. 4

    Is a priority scenario, an existing prototype entry, or a distinct contract test case.

  5. 5

    Has enough ownership and requirement evidence for an initial review.
